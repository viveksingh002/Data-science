# 📊 Data Science Projects

This repository contains Python projects covering **Object-Oriented Programming (OOP)**, **Data Analysis**, **Data Visualization**, and **NumPy** fundamentals. These projects are designed to strengthen Python programming and basic data science concepts through practical examples.

---

## ☕ Coffee Machine (OOP)

A simple command-line Coffee Machine built using Python Object-Oriented Programming concepts.

### Features
- Abstract Base Class (ABC)
- Inheritance
- Polymorphism
- Interactive Menu
- ASCII Art for each coffee

**Concepts Used:** Classes & Objects, Abstraction, Method Overriding, and Polymorphism.

---

## 🚢 Titanic Data Analysis

Performed **Exploratory Data Analysis (EDA)** on the Titanic dataset using **Pandas**, **NumPy**, and **Matplotlib**.

### Analysis Performed
- Data Summary & Statistics
- Age and Fare Distribution
- Survival Analysis
- Gender Distribution
- GroupBy Operations
- Data Visualization

**Visualizations:** Histogram, Box Plot, Bar Chart, Pie Chart, Scatter Plot, and Stacked Bar Chart.

---

## 📈 NumPy Student Score Analysis

A NumPy-based project for analyzing randomly generated student scores.

### Features
- Mean, Median & Standard Deviation
- Highest & Lowest Scores
- Percentile Calculation
- Failed & Distinction Students
- Score Normalization
- Reshaping Arrays
- Weighted Final Score Calculation
